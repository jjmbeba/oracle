# Select OpenWeather for MVP Weather Alerts

Oracle will use OpenWeather `One Call API 4.0` as the MVP weather-alert provider. Tomorrow.io was evaluated first but fails Oracle's MVP gate because its documented severe-weather coverage is region-limited and its live Events API required UUID-shaped `insights` identifiers instead of the documented category-name flow we tested. OpenWeather passed the gate with live non-U.S. evidence: `4.0` current-endpoint probes worked across Kenya, Japan, Brazil, and Germany, and `4.0` alert-detail payloads were confirmed live for Brazil and Germany. Those payloads include strong provider-native alert IDs, authoritative sender names, start and end times, localized descriptions, and category-like tags. One implementation caveat remains: `event` may be blank, so Oracle should derive the display title from `tags` and/or preferred localized descriptions when necessary.
